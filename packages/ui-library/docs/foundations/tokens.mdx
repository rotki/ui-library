# Tokens

The values the components draw with, for app code to use too. Each is a `--rui-*` variable with Tailwind
utilities on top, so an app that retunes a variable changes its own markup and the components together.
Switch the theme in the toolbar to see the dark values.

Steps of background that separate areas without a shadow.

## Shadows

Surfaces have no shadow: borders and background steps separate them. A shadow marks something that
floats above the page, and is named by that role.

    ['shadow-rui-menu', 'menus, dialogs'],
    ['shadow-rui-drawer', 'drawers, bottom sheets'],
  ].map(([token, use]) => (
    <div key={token} className="text-rui-text">

## Status and brand tints

Each color in three strengths, plus a solid fill with the text color that passes on it. Use `-soft` with
`-border` for a status panel, `-subtle` for a highlighted row, and `-fill` with `-foreground` for a badge.

## Stacking

Layers from lowest to highest. A menu or tooltip opened from a dialog sits above it, and a toast above
everything but a blocking screen. Put an app's own fixed parts on a layer instead of a raw `z-index`.

<table>
  <thead>
    <tr><th>Utility</th><th>Value</th><th>Holds</th></tr>
  </thead>
  <tbody>
    {[
      ['raised', 10, 'sticky headers and cells inside content'],
      ['app-bar', 20, 'the app bar, a docked drawer'],
      ['drawer', 30, 'a modal drawer and its scrim'],
      ['dialog', 1000, 'dialogs and bottom sheets'],
      ['menu', 1100, 'menus, selects, pickers'],
      ['tooltip', 1200, 'tooltips'],
      ['toast', 1300, 'notifications'],
      ['blocking', 2000, 'error and lock screens'],
    ].map(([layer, value, holds]) => (
      <tr key={layer}>
        <td><code>{`z-rui-${layer}`}</code></td>
        <td>{value}</td>
        <td>{holds}</td>
      </tr>
    ))}
  </tbody>
</table>

Each utility reads a variable of the same name, `--rui-z-raised` and on.
